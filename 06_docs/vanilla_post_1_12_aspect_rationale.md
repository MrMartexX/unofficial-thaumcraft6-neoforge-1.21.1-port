# Vanilla Post-1.12 Aspect Rationale Table

Target module: `05_neoforge_port`
Last updated: 2026-05-14

## Purpose

This document records every current Minecraft 1.21.1 vanilla stack sample that is not an exact mapped Thaumcraft 6 / Minecraft 1.12.2 parity target, and explains why its current aspect value exists.

Scope is generated from `07_Test_Instance_and_Comparisons/aspect_parity/reports/aspect_diff.json` rows with raw category `MODERN_ONLY`. That includes true post-1.12 items, flattened separate ids that no longer have the old 1.12 registry/meta shape, and current component samples for damage, potions, and stored enchantments. It does not duplicate legacy-equivalent stacks that already map and match 1.12 exactly.

Guide constraints applied: old `OreDictionary` categories become explicit tags, old metadata becomes explicit flattened ids or Data Components, and generated recipe values come from reload-safe cache data instead of lookup-time guessing.
