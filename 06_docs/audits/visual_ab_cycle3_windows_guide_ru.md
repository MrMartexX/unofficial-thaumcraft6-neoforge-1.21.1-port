# Visual A/B Harness — Cycle 3 (предварительная поставка)

## Границы подтверждения

Cycle 3 добавляет автономный HTML-просмотр пары скриншотов, JSON/Markdown-отчёт, проверяемый ZIP-пакет, безопасный повторный импорт.
Инструменты не меняют Minecraft, миров, исходных PNG или игровые настройки. Статусы игры всегда `NOT_RUN`, ревью `NOT_REVIEWED`.
Скриншоты G00 из предыдущего smoke подтверждают **транспорт F2**, но не визуальное соответствие: G00 требует отдельной калибровки и логов.

## Один объединённый офлайн-тест (без Minecraft)

В отдельном рабочем дереве, обновлённом до ветки Cycle 3:

```powershell
pwsh -NoProfile -File D:\TC6_AB_Cycle1\tools\visual-ab\tests\validate-offline.ps1
```

В конце должны появиться строки `PASS` для Cycle 1/2/3, тесты злонамеренных ZIP и недостоверной полноты. Тесты используют временные **синтетические** изображения.

## Работа с существующей сохранённой сессией

```powershell
$Run = 'D:\TC6_AB_Evidence\RUN_20261104T202107Z_5153ed72'
$Ab = 'D:\TC6_AB_Cycle1\tools\visual-ab'

pwsh -NoProfile -File "$Ab\comparison\compare.ps1" -RunPath $Run -SceneId 'G00.W-05.BASELINE.OVERVIEW'
pwsh -NoProfile -File "$Ab\reporting\report.ps1" -Action build -RunPath $Run
pwsh -NoProfile -File "$Ab\reporting\report.ps1" -Action export -RunPath $Run
```

HTML-файл из `htmlPath` открывается в обычном браузере локально. Он содержит обе PNG-копии внутри HTML, не использует внешние сервисы. Предусмотрены Side-by-side, Overlay и интерактивное Difference Image. При разных разрешениях сравнение пикселей отключается с пометкой `UNALIGNED_FRAMES`. Сравнивать такие кадры как равноценные нельзя.

В Overlay доступны два режима: **«Прозрачность»** (плавное наложение порта на оригинал) и **«Разделитель (wipe)»** (подвижная жёлтая вертикальная линия, слева порт, справа оригинал). Если кадры почти одинаковы, смена прозрачности может быть практически незаметна; перемещение линии позволяет убедиться, что управление работает. Старые HTML-файлы не обновляются: после загрузки нового Harness выберите `C` ещё раз, чтобы создать свежий просмотрщик.

В интерактивном `session/controller.ps1` также доступны пункты `C` (HTML-сравнение), `R` (создать отчёт и ZIP), `I` (проверка и необязательный импорт ZIP). Старые пункты `1`–`9`, `S`, `0` сохранены.

ZIP возвращает `path` и SHA-256. В пакет попадают только отчёт и зарегистрированные PNG; исходные `latest.log`, другие файлы игрового каталога, приватные заметки и записи видео **автоматически не включаются**.

```powershell
$Package = 'ВСТАВИТЬ_ПОЛНЫЙ_ПУТЬ_ИЗ_ВЫВОДА_EXPORT'
pwsh -NoProfile -File "$Ab\reporting\report.ps1" -Action verify-archive -ArchivePath $Package
pwsh -NoProfile -File "$Ab\reporting\report.ps1" -Action import -ArchivePath $Package -ImportRoot 'D:\TC6_AB_Imported'
```

Повторный импорт **того же неповреждённого ZIP** возвращает `ALREADY_IMPORTED_VERIFIED`; ничего не перезаписывает. Повреждённый ZIP или конфликтующее содержимое ранее импортированной папки вызывают ошибку.

## Что ещё не готово

- Истинное сопоставление условий G00: версия Java/NeoForge, Git SHA игрового порта, список модов, FOV, гамма, GUI Scale, разрешение, шейдеры и пакеты.
- Автоматический сбор/редактура журналов, видеозаписи, FFmpeg-клипы.
- Подтверждённая человеком подготовка реальных сцен, калибровка камер и визуальный `PASS`.
- Пользовательское тестирование добавленных пунктов `C/R/I` на Windows пока не проведено.

Оставьте исходную пользовательскую сессию и каталоги `saves` нетронутыми. Доказательства подготавливаются **вне Git**; никакие большие PNG или видео не публикуются автоматически.
