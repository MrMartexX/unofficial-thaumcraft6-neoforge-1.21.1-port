## Назначение

Разделить три вещи, которые нельзя смешивать:

1. **Файловая целостность:** зарегистрированная видеозапись существует и её SHA-256 совпадает.
2. **Метаданные видеоконтейнера:** настоящий `ffprobe` сообщает длительность, размеры и средний FPS видеопотока; запрошенный отрезок помещается в контейнер.
3. **Реальное совпадение кадров, эффектов и камер:** не проверяется ни пунктом 1, ни пунктом 2. Требует просмотра, калибровки и анализа уже полученных кадров.

## Новые инструменты

- `video/probe-core.ps1`: строгая обработка ограниченного JSON от ffprobe, проверка границ сегмента и формирование массива аргументов ffmpeg без оболочки.
- `video/probe.ps1 -Action inspect`: запускает **только ffprobe** для обоих видео выбранного `VPLAN_...`. Ожидание ограничено 30 сек на видео; SHA-256 проверяется до и после чтения. При выходе сегмента за пределы контейнера выдаётся ошибка.
- `video/probe.ps1 -Action preview`: **не запускает ffmpeg**. Сохраняет аргументы команд и предлагаемые новые пути вывода под `RUN_...` в приватном `video-previews.json`.
- `video/probe.ps1 -Action verify`: повторно считает SHA-256 источников, связанных с метаданными. Это не перепроверка реального потока и не покадровый PASS.
- `video/probe.ps1 -Action status`: число выполненных проверок метаданных и созданных предпросмотров.
- Контроллер: новый пункт `B`; в `T` можно увидеть ID видеопланов.

`ffprobe` поддерживает вывод JSON с выбранными полями. `ffmpeg` поддерживает ограничение перезаписи `-n`, точный поиск при перекодировании и `-t`. При этом перекодирование меняет пиксельные значения, а точность временного выравнивания нельзя гарантировать одним `-ss`. Документация: [ffprobe](https://ffmpeg.org/ffprobe.html), [ffmpeg](https://ffmpeg.org/ffmpeg.html).

## Реальная проверка видео (позже, когда будут готовые записи)

Для `inspect` требуется **доступный ffprobe** (часть установленного FFmpeg). Не нужно устанавливать его ради офлайн-тестов.

```powershell
$Ab = 'D:\TC6_AB_Cycle1\tools\visual-ab'
$Run = 'D:\TC6_AB_Evidence\RUN_20261104T202107Z_5153ed72'

# Сначала через меню M зарегистрировать два исходных видео (legacy и modern).
# Через T задать два независимых начала и общую длительность; скопировать PlanId.
$Plan = 'VPLAN_ЗАМЕНИТЬ_НА_РЕАЛЬНЫЙ_ID'

pwsh -NoProfile -File "$Ab\video\probe.ps1" -Action inspect -RunPath $Run -PlanId $Plan
pwsh -NoProfile -File "$Ab\video\probe.ps1" -Action preview -RunPath $Run -PlanId $Plan
pwsh -NoProfile -File "$Ab\video\probe.ps1" -Action status -RunPath $Run
pwsh -NoProfile -File "$Ab\video\probe.ps1" -Action verify -RunPath $Run
```

Можно передать `-FfprobePath 'D:\tools\ffmpeg\bin\ffprobe.exe'`, если `ffprobe` отсутствует в `PATH`. Исходные записи читаются, **не изменяются**. Предполагаемые выходные клипы не создаются; `ffmpeg` вообще не запускается.

## Безопасность и честность

- Не использовать `-y`: аргументы содержат `-n` (не перезаписывать существующий вывод).
- Приватные JSON (`video-probes.json`, `video-previews.json`) остаются внутри локального RUN и **не добавляются в ZIP**. Команды могут включать абсолютные пути и не предназначены для публикации.
- Синтетические тесты не доказывают, что `ffprobe` или `libx264` установлены на Windows; эти возможности проверяются отдельно только перед настоящим видеопилотом.
- При разных разрешениях `preview` блокируется: ресайзинг или обрезка не должны создавать видимость точного игрового равенства.
- Сходный средний FPS и достаточная длительность не означают синхронизацию анимаций. Временные смещения заданы человеком, не получены автоматическим поиском кадров.
- Все автоматически созданные статусы остаются `NOT_RUN`, `NOT_VERIFIED` и `PREVIEW_ONLY`; визуальный и игровой `PASS` не выставляется.
