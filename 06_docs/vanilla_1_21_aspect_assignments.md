# Vanilla 1.21 Aspect Assignment Audit

Target module: `05_neoforge_port`
Last updated: 2026-05-08

## Purpose

This document records every current manual vanilla 1.21 item assignment in `legacy_vanilla_modern_manual.json`. For the broader table of all modern-only, flattened, damage, potion, and stored-enchantment stack samples from the runtime comparer, use `06_docs/vanilla_post_1_12_aspect_rationale.md`.

The parity rule is: legacy 1.12 assignments win first; 1.21-only values are allowed only when they are explicit, documented, and based on a closest Thaumcraft 6 aspect category. No lookup-time name guessing is allowed.

## Automatic Rules

| Source | Applies to | Current policy |
|---|---|---|
| Exact legacy data | Same-concept ids such as coal, bucket, bedrock, clay, book | Direct JSON assignment from legacy values. |
| Legacy OreDictionary bridge | Modern common/vanilla tags for ores, ingots, gems, dusts, logs, leaves, saplings, stone families | Tags replace OreDictionary, using audited membership only. |
| Recipe-derived cache | Standard crafting outputs after server data reload | Generated from ingredient aspects using the legacy 0.75/count formula and remaining-item subtraction. |
| Stack-sensitive bonus rules | Armor, swords, bows, tools, hoes/shears, dyes, enchanted items/books | Implemented in `TCAspectStackRules` from legacy `getBonusTags`; enchantment level is multiplied by 3 and magic bonus follows legacy rarity weight. |
| Potion component rules | Potion, splash potion, lingering potion, tipped arrow stacks with `POTION_CONTENTS` | Comparable legacy variants use final 1.12 runtime outputs; 1.21-only potion effects use explicit component policy values. |
| Exclusions | Vanilla spawn eggs, firework star/rocket, infested blocks, empty component-only splash/lingering/tipped ids | These remain no-aspect for 1.12 parity unless an explicit expected-divergence decision is made. |
