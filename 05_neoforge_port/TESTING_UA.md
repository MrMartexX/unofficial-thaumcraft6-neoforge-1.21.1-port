# Thaumic Research 0.1.0-alpha1 — тестування

Це альфа-збірка порту Thaumcraft 6 на Minecraft 1.21.1 + NeoForge 21.1.248.

## Вимоги

- Minecraft 1.21.1
- NeoForge 21.1.248
- Java 21 x64
- Для першого тесту рекомендується чистий профіль без інших модів
- Створіть новий тестовий світ. Не використовуйте важливий існуючий світ без резервної копії.

## Встановлення клієнта

1. Встановіть NeoForge 21.1.248 для Minecraft 1.21.1.
2. Запустіть профіль один раз і закрийте Minecraft.
3. Скопіюйте JAR `thaumcraft-0.1.0-alpha1.jar` до папки `mods` профілю.
4. Запустіть Minecraft через NeoForge 1.21.1.
5. У списку модів має відображатися `Thaumic Research`.

## Перший smoke-test

Перевірте в такому порядку:

1. Головне меню та створення нового світу не падають.
2. У творчому режимі відкривається вкладка мода й присутні базові предмети/блоки.
3. Перевірте Thaumometer і сканування ванільних предметів/сутностей.
4. Перевірте Research Table і базовий шлях досліджень.
5. Відкрийте Thaumonomicon і пройдіть кілька перших досліджень.
6. Перевірте Arcane Workbench і кілька базових arcane recipes.
7. Перевірте Crucible, essentia jars/tubes та простий перенос essentia.
8. Перевірте Infusion Matrix на простому доступному рецепті.
9. Перевірте aura/vis/flux у звичайній грі.
10. Перезайдіть у світ і переконайтеся, що прогрес досліджень, BlockEntity і essentia збереглися.

## Dedicated server

Для першого серверного тесту використовуйте чистий NeoForge 21.1.248 server з Java 21 і той самий JAR у `mods`.

CI цього репозиторію після `gradlew build` також виконує dedicated-server smoke test. Це перевіряє старт сервера, але не замінює повний ігровий тест.

## Відомий статус альфи

Поточна кодова база вже містить великий обсяг TC6-порту: аспекти/сканування, research/Thaumonomicon, aura, значну частину crafting/alchemy/infusion/essentia, warp, частину сутностей, taint/flux та низку пристроїв. Однак це ще не фінальний 1:1 порт.

Очікувані незавершені області включають частину golem logistics/seals, окремі focus projectile/cloud/mine сценарії, turrets, частину worldgen/spawn integration, деякі сутності та їх точну renderer/model/particle parity, а також частину візуального полірування.

## Що надсилати при помилці

Надішліть:

- `latest.log`
- crash-report, якщо він створився
- скрін того, що відбувалося перед помилкою
- назву предмета/блоку/дослідження
- одиночна гра чи сервер
- точні кроки від запуску світу до помилки

Для проблеми з дослідженням бажано додати назву research key/сторінки. Для BlockEntity або essentia — координати блока й те, що до нього було підключено.
