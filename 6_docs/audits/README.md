# 6_docs/audits

Curated audit results and summaries go here.

Use this folder for reports that are worth keeping across sessions, such as:

- asset parity summaries;
- research requirement summaries;
- build and dedicated server smoke-test summaries;
- known visual parity decisions.

Do not use this folder for every local generated file. Temporary raw output should stay in `tools/reports/` or local-only ignored files.
